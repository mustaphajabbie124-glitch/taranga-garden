# Taranga Garden 

A modern and responsive agricultural website built as a personal web development project.

## About

Taranga Garden is a personal web development project focused on creating a clean, modern, and responsive website for an agricultural business.

The project showcases agricultural produce, farming activities, agricultural machinery, and services through a simple and user-friendly website.

I built this project to strengthen my practical skills in front-end web development while creating a realistic website that could be adapted for a real business.

## Features

- Responsive design
- Mobile-friendly navigation
- Sticky navigation bar
- Mobile hamburger menu
- Smooth scrolling navigation
- Agricultural produce section
- Agricultural services section
- Image gallery
- Full-screen image viewer
- WhatsApp contact link
- Email contact link
- Responsive layout for desktop, tablet, and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
